# TidyBox 隐私说明

最后更新：2026-10-28

## 一句话

TidyBox 的磁盘分析、右键菜单管理、卸载工具和背单词都在你的电脑上运行，**不会联网，也不会收集使用数据**。唯一会联网的是设置页里的“发送反馈”，而且只有你点击“发送”的那一刻才会发出请求。

个别链接（例如“在 SteamDB 搜索”）会在你的默认浏览器里打开网页，访问是由浏览器发起的，TidyBox 不会向那个网站发送任何数据。

## 发送反馈时会发送什么

- 反馈类型（建议 / 错误 / 其他）。
- 你写的内容。
- 你选填的联系方式（邮箱、QQ、微信等，不填就不发送）。
- TidyBox 的版本号。
- 如果你选的是“错误”，并且勾选了“附带最近的运行日志”（默认勾选，可以取消）：最近的一小段运行日志，最多 64 KB。发送前会把日志里你的用户目录路径、Windows 用户名和电脑名替换成占位符，你可以在发送前点开“查看将发送的日志”看到将要发送的全部内容。

## 不会收集什么

系统版本、硬件信息、设备标识、使用统计，以及你的文件和磁盘内容。

## IP 地址

反馈请求经由 Cloudflare 的网络转发。服务器只保存你 IP 地址的哈希值（加盐的 SHA-256），用来防止有人批量刷屏；不保存原始 IP 地址。

## 数据存在哪里、保留多久

反馈保存在作者的 Cloudflare D1 数据库里，只有作者可以查看。没有自动删除，作者会手动清理。如果你想删除自己提交过的内容，请通过 Microsoft Store 页面上的联系方式告诉我们。

## 你电脑上的日志

TidyBox 会在 `%LOCALAPPDATA%\TidyBox\logs` 里保存一份很小的日志，只记录程序启动、未处理的错误、模块加载失败等信息。它不会被自动上传，只有按上面说的“错误”反馈并勾选附带时，才会随反馈发送。你可以随时删除这个文件夹。
